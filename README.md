## Цель
Научиться описывать запись объекта структурой struct, хранить коллекцию записей в vector, читать и проверять данные из текстового файла и сохранять одинаковый отчёт на экране и в файле.

## Описание
Файл содержит сведения о компьютерных играх. Программа выводит игры заданного жанра, определяет среди них самую последнюю, а также находит игру с наименьшим объёмом оперативной памяти среди всех игр. Чтение файла, поиск и запись отчёта выполняют отдельные функции. При ошибке в строке файла программа выводит ERROR line N и завершается без отчёта.

## Исходные данные
Данные вводятся с клавиатуры: путь к входному файлу, путь к выходному файлу, затем жанр (каждое значение на отдельной строке).

Каждая строка входного файла описывает одну игру, поля разделены точкой с запятой: название;жанр;год выхода;процессор;оперативная память в мегабайтах. Не более 100 строк, пустые строки не допускаются, год от 1950 до 2100.

Пример файла:
- Doom;Action;1993;Intel 486;8
- Quake;Action;1996;Pentium;16
- Portal;Puzzle;2007;Core 2 Duo;512
- Half-Life 2;Action;2004;Pentium 4;256
- Tetris;Puzzle;1984;Intel 8086;1

## Ожидаемые результаты
Для жанра Action и файла из примера отчёт содержит:
- список игр Doom, Quake и Half-Life 2 со всеми сведениями
- самую последнюю игру жанра: Half-Life 2, 2004
- игру с наименьшей оперативной памятью среди всех: Tetris, 1 MB

Если игр жанра нет, выводится EMPTY и NONE. Отчёт на экране совпадает с отчётом в выходном файле.
